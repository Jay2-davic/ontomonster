## FAIR Principles Alignment

OntoMonster supports the FAIR principles (Findable, Accessible, Interoperable, Reusable) for data management and ontology development:

- **Findable**: Terms are searchable and organized hierarchically
- **Accessible**: Open source, runs locally, no proprietary dependencies
- **Interoperable**: Built on BFO/CCO, exports to standard formats (OWL, LinkML, SHACL)
- **Reusable**: Clear licensing (BSD-3-Clause), comprehensive documentation, data provenance tracking

For more on FAIR principles, see: https://www.go-fair.org/fair-principles/

## Ontology Foundations

### Basic Formal Ontology (BFO)
https://basic-formal-ontology.org/

The upper-level ontology framework that provides the philosophical foundation for OntoMonster's ontology structure.

### Common Core Ontologies (CCO)
https://www.commoncoreontologies.org/

Mid-level ontology extensions of BFO that OntoMonster uses for domain standardization.
